# 🚀 Démarrage Rapide - 5 Minutes

## 1️⃣ Lancer l'Application

```bash
cd /home/user/PHYSIO-APP
npm install                  # Première fois seulement
npm run dev                  # Lance l'application
```

➡️ Ouvrez : **http://localhost:5173**

---

## 2️⃣ Créer Votre Premier Bilan

### ✏️ Remplir le Formulaire (10 étapes)

1. **Patient** : Nom, prénom, date de naissance
2. **Chirurgie** : Date opération, type de ligamentoplastie, genou opéré
3. **Douleur** : Cliquez sur les échelles (0-10)
4. **Stroke Test** : Sélectionnez le résultat observé
5. **ROM** : Flexion et extension (en degrés)
6. **Force** : Testing 0-5 pour chaque muscle
7. **Fonctionnel** : Marche, escaliers, unipodal
8. **Scores** : IKDC, Lysholm (optionnel)
9. **Objectifs** : Court/Moyen/Long terme
10. **Plan** : Techniques, exercices, conseils

### 💾 Sauvegarder

Cliquez sur **"Sauvegarder le bilan"** en bas de page

---

## 3️⃣ Utiliser l'Assistant IA

### 📍 Icône Flottante 💡
Cliquez en bas à droite après sauvegarde

### 📊 3 Onglets

**Aperçu** : Score de récupération + Recommandations IA
**Export** : Sauvegarder / Export HTML / Imprimer
**Historique** : Vos bilans précédents

---

## 4️⃣ Exporter le Bilan

1. Cliquez sur l'icône 💡
2. Onglet **"Export"**
3. Bouton **"Export HTML"**
4. Fichier téléchargé : `Bilan_NOM_Prenom_Date.html`

✅ **Résultat** : Document professionnel avec charte A2P, tous les calculs, badges et recommandations !

---
